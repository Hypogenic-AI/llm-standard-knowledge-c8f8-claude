# How much volume is *standard knowledge* in LLMs?

A quantitative estimate of the fraction of LLM parameters dedicated to
encoding **standard categorical and conditional knowledge** — the
"everyone-knows-this" facts a competent reader can recite about peanuts,
Georgia, or symphony orchestras. Generated by NeuriCo, 2026-04-27.

## Key findings

Across Pythia-{160M, 410M, 1B, 2.8B} probed with BEAR (7,731 relational
facts) + TAXI (1,435 categorical / property queries):

- Standard knowledge consumes **0.00006%–0.00022%** of the model's bit
  budget at the Allen-Zhu 2 bpp ceiling — **roughly 1 part in a million**
  of stored capacity. This confirms the qualitative hypothesis ("a very
  small component") with a precise number.
- **The fraction shrinks with model scale.** 410M → 1B halves it,
  1B → 2.8B halves it again. Bootstrap 95% CIs at the larger sizes are
  disjoint from those at smaller sizes (statistically reliable trend).
- **Acquired bits scale sub-linearly** (slope ≈ 0.50 in log-log; R² = 0.92,
  p = 0.04). Adding a parameter buys only ~0.5 fractional bits of new
  standard knowledge, so the share dilutes as capacity grows linearly.
- **Categorical knowledge is better-known per fact** (TAXI 23–30% acc) than
  relational knowledge (BEAR 6–13%), but contributes fewer aggregate bits.
- The **best-known** BEAR relations are the most "standard": taxonomic
  level, head of government, capital, ownership — exactly what the
  hypothesis says LLMs should hold.

See **REPORT.md** for the full write-up with statistics, scaling
regression, per-relation tables, and discussion.

## How to reproduce

```bash
# 1. Set up isolated environment (already created here)
source .venv/bin/activate

# 2. Run probes (per-model, ~1–13 min each on an A6000)
python src/run_one.py --model EleutherAI/pythia-160m
python src/run_one.py --model EleutherAI/pythia-410m
python src/run_one.py --model EleutherAI/pythia-1b
python src/run_one.py --model EleutherAI/pythia-2.8b

# 3. Aggregate + analyse + plot
python src/analyze.py        # builds figures/, scaling regression, per-fact footprint
python src/breakdown.py      # bootstrap CIs and per-relation table
```

Pre-downloaded datasets live in `datasets/bear/` and `datasets/taxi/`. Model
checkpoints are pulled automatically via 🤗 Transformers.

## Models and hardware

- **Pythia-{160M, 410M, 1B, 2.8B}** loaded in fp16 via 🤗 Transformers.
- **GPU**: NVIDIA RTX A6000 (49 GB), batch_size = 24 for log-likelihood
  scoring. Total compute time across the four models: ~25 minutes (4
  GPUs running in parallel).
- **Random seed**: 42 (set in `src/probe_utils.py:set_seed`).

For the precise methodology, statistical tests, and discussion, see
[REPORT.md](REPORT.md).
